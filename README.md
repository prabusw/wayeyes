#  swayeyes - Lightweight tool for Sway to prevent eye strain


swayeyes is a lightweight tool for [SwayWM](https://swaywm.org/) to
prevent eye strain. It is written using shell scripts only and uses
tools which are built into Sway.

* Schedules regular screen blanking/locking intervals to prevent eye strain.
* Pre-blanking notification alerts.
* Detailed logging of activity.

A openRC User service script is provided here which can be easily
adapted to systemd.

Refer to my [dotiles](https://git.sr.ht/~prabuanand/dotfiles) for how this tool can
be integrated with tools like [tofi](https://github.com/philj56/tofi)
and [mako](https://github.com/emersion/mako)

Please feedback, if there are issues when using the tool.
